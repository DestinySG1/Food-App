# Tagesteller (Arbeitstitel)

Eigene Kalorien- und Makro-Tracker-Web-App. Läuft im Handy-Browser und lässt sich auf den Startbildschirm legen.

- `npm install` – Abhängigkeiten installieren
- `npm run dev` – lokal starten
- `npm test` – Tests der Zielberechnung
- `npm run build` – fertige App in `dist/`

Daten bleiben lokal im Browser des Geräts.
